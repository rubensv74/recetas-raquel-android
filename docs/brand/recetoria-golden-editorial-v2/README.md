# Recetoria — paquete de identidad visual

Versión 2.0 — Golden Editorial · 15 de agosto de 2026

## Concepto

El símbolo combina una **R**, una ficha digital y el pliegue de una página. El sistema cromático parte de la interfaz editorial de Recetoria: bronce tostado, oro antiguo, marfil y tinta espresso. El dorado comunica autoría y calidad culinaria; no sustituye los colores semánticos de seguridad.

Lema: **Tus recetas, con confianza**.

## Archivos

- `logo/recetoria-symbol.svg`: símbolo principal, fondo transparente.
- `logo/recetoria-lockup-light.svg`: firma horizontal para fondos claros.
- `logo/recetoria-lockup-dark.svg`: firma horizontal para fondos oscuros.
- `logo/recetoria-symbol-monochrome.svg`: versión de una tinta.
- `android/ic_launcher_foreground.xml`: foreground de icono adaptativo Android.
- `android/ic_launcher_background.xml`: color de fondo del icono adaptativo.
- `android/splash-recetoria.svg`: composición de splash screen.
- `png/`: exportaciones PNG listas para revisión e integración.
- `brand-tokens.json`: colores y tipografía en formato reutilizable.
- `USAGE.md`: reglas básicas y especificaciones de publicación.

## Principio de uso

No añadir hojas, alimentos, cubiertos, gorros de chef, escudos ni checks alrededor del símbolo. No usar efectos metálicos, brillos ni degradados dorados: esta es una marca editorial, no una identidad de lujo ornamental.
